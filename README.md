# 📋 Interactive To-Do List

A sleek, interactive task management web application built to practice dynamic DOM manipulation and responsive styling. 

This project focuses on real-time user feedback, precise event handling, and clean visual layouts to deliver a smooth user experience.

This project is hosted using GitHub pages. You can test it here:

## 🎨 Technologies Used
The repository breaks down into the following language distribution:
* **JavaScript (57.8%):** Drives the core application logic, event listener and DOM changes. 
* **CSS (28.0%):** Handles the layout structure, typography, button states, icons and dynamic content.
* **HTML (14.2%):** Provides the semantic input elements, containers, and structural base for the application.

## ✨ Key Features & Functionality
* 💬 **Dynamic Task Confirmation:** Every single time you input and save a new task, the application dynamically updates to prompt: *"You need to + [your added task]"*.
* ✔️ **Task Completion:** Clicking or checking off a task triggers an instant strikethrough effect across the text to visually mark it as completed.
* 🗑️ **Trashcan Delete Icon:** Each item includes a dedicated trashcan icon, allowing you to instantly clear individual tasks from your list.
* ⏱️ **Session Memory:** Built using active session state logic. The list populates dynamically during use and completely resets once you refresh or close the page.

## 🚀 Technical Concepts Applied
* Managing dynamic template literals and injecting content directly into the DOM using JavaScript.
* Listening to text inputs, form submission events, and button clicks simultaneously.
* Utilizing state toggling to apply conditional CSS classes, like background gradient, transparency and text decoration for completed tasks.


## 🚀 Key Learning Outcomes
* **State & Memory Management:** Evaluated different data persistence methods to deliberately implement a lightweight, session-based memory architecture optimal for this project's scope.
* **Event-Driven Programming:** Mastered the execution of event listeners to capture user inputs and trigger real-time actions synchronously.
* **Advanced DOM Manipulation:** Deepened understanding of the DOM tree structure, dynamically creating, updating, and removing nodes based on user interaction.
